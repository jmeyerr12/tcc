# PCAP dos experimentos

Os arquivos de captura não são armazenados no Git devido ao tamanho.

O experimento usa:

```text
CICIDS2017-Monday-mtu1500.pcap
```

SHA-256 esperado:

```text
a652a6dfafa1312f3f9d7fcb01cf4ec045826d1a91a4b38da346be4df66225d6
```

Depois de clonar o projeto, copie o arquivo para este diretório e confira:

```bash
sha256sum experiments/pcaps/CICIDS2017-Monday-mtu1500.pcap
```
